# Jemal Ali — Portfolio

A premium animated developer portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Create a GitHub repository, e.g. `jemal-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md`.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Choose `main` and `/ (root)`.
6. Save.

Update the GitHub and email links in `index.html` with your real profile/contact details.
